### Release dependency evidence

The final local artifact is `veyra:remediation-local`, Linux amd64 digest `sha256:6f9d96547affb29ab31a14d223bc6fd5f3ba09323fbe8faae4dd89f1cf6839ac`. Django and Channels checks, a 22-case Linux suite, and package consistency passed. OSV returned zero matches across 39 release queries and 78 Windows queries. The prior Linux image contained cryptography 46.0.7 and pip 25.0.1. The original OSV scan returned seven identifiers for cryptography and twelve for pip, including aliases. The cryptography maintainer identifies 48.0.1 as the fix for GHSA-537c-gmf6-5ccf. The affected OpenSSL ASN.1 path was not identified in Veyra's application inputs. The app uses Fernet and OIDC/JWT verification. For pip, the recorded findings include the fallback source-archive unpacking issue CVE-2025-8869. The application does not invoke pip at runtime. The release selects pinned binary wheels and builds Veyra only from the checked-out project. [cryptography advisory](https://github.com/pyca/cryptography/security/advisories/GHSA-537c-gmf6-5ccf) · [OpenSSL advisory](https://openssl-library.org/news/secadv/20260609.txt) · [pip advisory](https://github.com/advisories/GHSA-4xh5-x5gv-qwph) · [pip releases](https://pip.pypa.io/en/stable/news/)
